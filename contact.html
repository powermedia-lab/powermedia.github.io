常见问题

你可能还想确认这些

部署一套环境需要多久？

单机 Docker 环境通常当天可完成主链路验证；涉及集群、DRM 与国产数据库的完整交付，视环境准备与合规要求，一般按周计。我们会在演示后给出分阶段计划。

支持内网或离线部署吗？

支持。产品可私有化部署在客户内网，不依赖公有云；授权支持离线 .lic 文件（签名验签 + 机器指纹绑定），适合隔离网络环境。

能接入我们现有的平台和账号体系吗？

可以。提供 REST API 与 OAuth 客户端凭证，媒体入库、播放授权、任务查询均可由上层平台调用；界面支持品牌定制，也可仅使用接口并替换前端。账号体系对接方式需结合现有认证协议，在方案阶段确认。

支持哪些终端？

以浏览器为主：Chrome、Edge、Safari、Firefox 及主流移动端浏览器；HLS / DASH 自适应，播放器引擎按内核自动切换。原生 App 可通过嵌入播放器或直接对接清单与令牌集成。

支持从现有系统迁移数据吗？

提供 db-migrate 工具，支持 SQLite 到 PostgreSQL / MySQL / DM8 / KingbaseES 的全量与增量迁移，逐表校验行数与关键字段，迁移失败可回滚。

授权如何计价？

按版本、授权台数与单机播放并发配额核定，预转码等能力按需开启。具体报价请提供业务规模与合规要求，我们会给出对应配置。

01 / 播放引擎

播放请求到达时，
才开始准备切片

传统流程需要等待整片转码完成后才能播放。PowerMedia 在播放请求到达后先返回清单，再按需生成分片，并随播放进度继续处理，减少起播等待。

  • JIT 按需切片：首片生成即可起播，后续分片随播放进度补齐
  • 多协议自适应：直链 MP4、HLS、DASH，按终端能力自动选择
  • 多引擎回退：不同浏览器内核下自动切换播放器实现
  • 体验细节：跨端续播、进度缩略图雪碧图、多音轨切换

02 / 入库与元数据

将媒体文件转化为可管理的资产

扫描、识别、刮削、归并与发布均具备状态记录和恢复能力，服务重启后无需从头处理。

多库多路径

电影、剧集、动漫、音乐、图片、文档分库管理，同一文件可归属多库，路径变更由扫描协调处理。

元数据刮削

对接 TMDB、TVDB、豆瓣、Bangumi、OMDb；字段缺失时由 AI 辅助补全，海报在扫描期预捕获。

可恢复摄入

入队、认领、崩溃恢复三段式，不可变处理生命周期；重复文件按内容指纹去重，避免重复转码。

剧集与季集模型

季 / 集结构、特别篇、多版本同片归并；剧集级封面与简介继承，避免逐集手工维护。

发布策略 v2

处理完成不等于对外可见。发布按 DAG 编排，元数据、海报、切片、字幕齐备才转“可播”，避免未完整处理的媒体提前上线。

文档与图片

PDF / Office / 电子书解析为可读页面，扫描件走 OCR 与版面还原；图片按人脸、地点、场景自动归类。

03 / 转码与调度

按热度分配算力，
优先保障播放

预转码应根据实际播放热度分配算力，而不是对所有片源做全量处理。PowerMedia 通过热度候选、资源门控和集群并行控制成本与处理时长。

  • 候选闭包：运营指定（P0）优先，其余按播放热度、收藏、入库时间等六组特征排序，默认 120 片
  • 集群编排：local / 数据库 / Redis 三种方案，跨节点并行不同清晰度，协调者故障 60 秒内接管
  • 可解释准入：每次拒绝均记录原因（容量、公平性、老化、库配额），便于排查
  • 成本核算：无人播放期间的预热成本单独统计，便于评估是否继续预热

04 / 内容保护

地址泄露不等于可以播放

六层纵深防御覆盖视频、音频、图片与文档：分别管理内容加密、播放授权与分享链接——文件保持加密，播放需要凭证，链接支持撤销，输出带溯源水印。

01

Widevine

面向浏览器与 Android 生态的主流 DRM，L1 / L3 按终端能力协商。

02

FairPlay

面向 Apple 生态，支持 iOS、iPadOS、macOS 与 Safari 播放。

03

PowerDRM

自有方案，适合私有化环境内闭环部署，不依赖外部许可证服务。

04

HLS AES-128

轻量加密方案，部署成本低；密钥由内置服务签发，15 分钟过期。

可管理、可审计的媒体分享

媒体分享支持匿名访问、访问口令、有效期与嵌入代码；已发出的链接在授权变更后仍可访问（仅凭分享 token），新建分享则需要专业版及以上授权。

  • 访问控制：口令、有效期、域名白名单、嵌入播放器
  • 可审计：我的分享集中管理，访问记录可查、可撤销
  • 加密媒体可分享：DRM 片源同样支持分享，无需为分享降低保护级别
六层纵深防御
L1

传输加密

TLS 1.3 全链路加密，防中间人嗅探

L2

令牌访问

签名 URL 绑定用户与 IP，15 分钟过期，防转发与重放

L3

分片加密

HLS AES-128 加密分片，客户端拿不到完整明文

L4

污染输出

图片双水印加降质，文档逐页渲染为图片

L5

客户端加固

安全响应头与行为拦截，防截取与调试

L6

溯源水印

可见与隐写双层水印，泄露后可定位来源

查看防泄露方案详解：分片加密 · 双重水印 · 逐页渲染 · 客户端加固
05 / 字幕与语音

一个片源，服务多语种观众

自动提取已有字幕、识别图形字幕与语音内容，并通过模型校对机器译稿，减少人工整理工作。

字幕提取与识别

内嵌文本轨直接提取，Sidecar 文件自动扫描匹配；PGS 图形字幕通过 OCR 还原为文本，再统一转成 WebVTT。

语音转写（ASR）

基于 Whisper 的本地转写，支持中英日韩等语种；长音频分段处理，时间轴与画面自动对齐。

多语翻译

中文（简 / 繁）、英语、日语、韩语互译，按语种生成独立字幕轨，播放器内自由切换。

模型校对

机器译稿经大模型校对术语、断句与人名，生成可供发布的版本，减少人工逐句校对工作。

06 / 平台与集成

适配现有平台
与部署环境

PowerMedia 可独立部署，也可作为媒体微服务被上层平台调用。数据库、认证方式与部署形态均可按需选择。

  • 五种数据库：SQLite、PostgreSQL、MySQL、达梦 DM8、金仓 KingbaseES，方言层统一抽象

  • 接口鉴权：JWT、OAuth 客户端凭证、Bearer / Query Token 双模式，适配播放器与后端调用
  • 品牌定制：站点名称、Logo、主题色可替换，对外呈现属于你的产品

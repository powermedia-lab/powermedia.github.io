首页/内容保护

六层纵深防御，
泄露可防、可溯

从传输、访问、内容、输出、客户端到溯源，六层防线逐层兜底：拿到地址放不出来，录屏下载带标记，内容外流后仍能定位到具体用户与会话。

六层防御 分类防线 溯源水印 客户端加固 配置与默认值
01 / 六层纵深防御

每层只解决一类威胁，层层兜底

单层防护总会被绕过，纵深的意义在于：任何一层失效，下一层仍然有效。六层全部由服务端统一配置，不依赖某个客户端自觉。

L1

TLS 1.3 · 传输加密

全链路 HTTPS 传输，防止中间人嗅探与流量劫持，是所有上层防线的入口条件。

L2

签名 URL 令牌 · 访问控制

播放与资源请求凭签名令牌访问，令牌绑定用户、IP 与会话，默认 15 分钟过期，Nonce 防重放——转发 URL 给他人、过期重放均无法访问。

L3

HLS AES-128 · 分片加密

视频与音频以加密分片下发，客户端只能拿到碎片与一把会过期的解密密钥，拿不到完整明文；密钥与内容分离管理，并可升级 Widevine / FairPlay / PowerDRM。

L4

污染输出 · 输出防护

无法分片的类型直接改写输出：图片双水印加降质输出、文档逐页渲染为图片。内容即使离开平台，也已带上标识且不可直接复用。

L5

客户端加固 · 端侧防线

安全响应头（HSTS、X-Frame-Options、CSP 等）配合前端拦截：禁止右键 / 拖拽 / 文本选择，打印时模糊或隐藏，检测到 DevTools 调试即模糊画面。

L6

溯源水印 · 泄露追责

可见水印 + 隐写水印双层标识观众与会话。内容一旦外流，可从截图中提取载荷，定位到具体用户、会话与时间，为追责提供依据。

02 / 分类防线

四类媒体，四种针对性策略

视频可以分片，图片必须完整渲染，文档的威胁是文本可复制——威胁模型不同，防线设计也不同。

视频与音频：分片加密 + 会话水印

加密存储的源文件按需解密、经 HLS 打包为 AES-128 加密分片，播放凭短期令牌与密钥授权。水印跟随单个观众：可见水印标出用户，隐写层以块级亮度芯片嵌入标记编号，翻录内容仍可提取溯源。

客户端拿不到完整明文

图片：原图永不离开服务端

图片无法分片加密，改为污染输出：解密后叠加可见水印平铺与隐写溯源信息，再经 JPEG 压缩输出并禁止缓存。浏览器拿到的是带标降质图，原图始终留在服务端，缩略图不打标。

双水印 + 降质 + no-store

文档：逐页渲染，文本不出服务端

文档的威胁是文本天然可复制。开启逐页渲染后，阅读器不再接收原始 PDF，而是逐页加载带水印的页图，正文文本不进入浏览器；可同时禁止 PDF 原件预览与下载，整包导出无从谈起。

每页水印 · 可禁原件

全类型底座：信封加密存储

所有类型共用同一加密底座：每个文件使用独立的随机 DEK 加密，DEK 由 KEK 包装后入库，密钥与密文分离存放；KEK 定期轮换只需更新数据库中的包装结果，无需重新加密文件。缩略图等中间产物同样加密落盘，明文从不落盘。

DEK / KEK 分离 · 密钥轮换
03 / 溯源水印

泄露之后，
答案在截图里

水印不是装饰性威慑，而是一条可执行的取证链路：每一份输出都携带观众身份，管理端可直接对泄露材料提取与比对。

  • 可见层：半透明文字水印（默认按用户标识生成），支持自定义模板、位置、字号与透明度
  • 隐写层：块级亮度芯片嵌入 48 bit 载荷（同步字节 + 标记编号 + CRC 校验），肉眼不可见、有损压缩后仍可提取
  • 提取与查询：管理端提交泄露片段即可提取标记，支持有参考帧的知情解码与无参考的盲提取；可按用户、会话、媒体、任务检索水印记录
  • 覆盖范围：视频、图片、文档页图共用同一水印引擎，载荷格式统一，一处泄露、全类型可查
watermark · 载荷与提取（示意）

04 / 客户端加固

让“随手保存”失效

端侧防线挡不住专业工具，但足以拦截绝大多数日常泄露路径；配合 L6 溯源水印，绕过加固的行为仍会留下证据。

  • 交互拦截：禁用右键菜单、拖拽与文本选择，图片和文档页上方覆盖透明防护层，长按与“另存图片”失效
  • 快捷键与打印：拦截 Ctrl/Cmd+S、P、C、U 等保存与查看源码快捷键；打印时页面模糊或直接隐藏
  • 调试检测：检测到 DevTools 打开后自动模糊画面，阻止 DOM 抓取与资源导出
  • 离开清理：页面关闭时暂停播放并清空媒体地址，减少缓存残留

HTTP 安全响应头

HSTS强制 HTTPS 长期生效
X-Content-Type-Options阻止 MIME 嗅探
X-Frame-Options禁止被第三方页面嵌入
Referrer-Policy不向外部泄露来源地址
COOP / CORP / COEP跨源隔离，防侧信道读取
CSP限制脚本与资源加载范围
Cache-Control受保护内容 no-store，不留本地缓存

播放类请求（切片、清单、字幕）不受 no-store 限制，兼顾防泄露与播放性能。输入框与文本域不做按键拦截，不影响正常使用。

05 / 配置与默认值

默认关闭，按合规要求开启

防泄露各模块默认不启用，升级不会改变现有站点行为；按项目的合规等级逐项开启，参数范围如下。

模块默认状态说明
视频 / 音频水印（watermark） 关闭 可见与隐写两层可独立开关，未指定时两层同时开启
图片防护（image_protect） 关闭 双水印输出；可选放行带授权参数的原图下载
文档逐页渲染（doc_protect） 关闭 开启后阅读器改用页图，可同时禁止 PDF 原件预览
客户端加固（client_harden） 关闭 安全响应头与前端拦截整体开关，各子项可细调
常用参数
可见水印透明度 0.10 范围 0.05–0.6，按观感与醒目程度权衡
输出 JPEG 质量 85 范围 60–95，压低可进一步降低盗用价值
隐写强度 4 范围 1–8，数值越高越抗压缩，对画质影响越大
图片输出宽度上限 2560 px 范围 640–8192，超出先缩放再输出
访问令牌有效期 15 min 与 HLS 密钥生命周期配合

各模块的开启与参数以项目交付配置为准；演示时可用你的真实片源验证水印提取流程。
